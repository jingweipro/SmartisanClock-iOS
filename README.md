# 锤子时钟 iOS 复刻

面向个人自用测试的 iOS 26+ 原生复刻。以 SmartisanClock-Revived 的布局、原始位图、字体、音效和交互参数为基准，使用 SwiftUI 与 AlarmKit 在 iPhone 上重建。

## 当前范围

- 世界时钟、原城市库与城市搜索
- 闹钟列表、原式时间选择器、重复/铃声/标签编辑
- AlarmKit 系统闹钟调度与应用内原式响铃面板
- 原式机械秒表、圈次、按键音效
- 经典下拉环与水平滑尺两套计时器
- 原式底部栏、图标、机械表盘、弹回帧动画、字体和音效

## 运行

使用 Xcode 26.2 或更高版本打开 `SmartisanClockiOS.xcodeproj`，选择 iOS 26+ 的模拟器或已连接 iPhone 后运行。真机首次创建闹钟时需要允许系统闹钟权限。经典计时器从右侧白色环下拉设置时长，水平计时器在底部滑动刻度。
